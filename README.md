# factory-game

A tiny browser-based factory automation prototype written in vanilla JavaScript. Chain auto-drills, furnaces, assemblers, and solar fields together to grow your throughput while keeping the grid balanced.

## Running locally

Open `index.html` in your browser or serve the directory with a static file server (for example, `python -m http.server 8000`).

## Playing directly from GitHub
You can publish the game with GitHub Pages to play it without downloading:
1. Open your fork of the repository on GitHub and go to **Settings → Pages**.
2. Under **Source**, select the `main` branch and keep the root folder (`/`). Save the change.
3. After GitHub finishes deploying (usually a minute or two), the game will be available at `https://<your-username>.github.io/factory-game/`.
